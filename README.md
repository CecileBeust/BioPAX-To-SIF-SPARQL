# BioPAX to SIF abstraction in SPARQL

This repository contains SPARQL queries for BioPAX to SIF abstraction.

The 14 SPARQL queries corresponding to the 14 SIF abstraction rules are available in the `Scripts/SPARQLqueries` folder.

We provide two Jupyter notebboks that execute the 14 SPARQL queries on the BioPAX exports of two pathways databases (Reactome and PathBank):
- `Scripts/abstract_biopax_sif_reactome.ipynb`
- `Scripts/abstract_biopax_sif_pathbank.ipynb`
